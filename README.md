# Coba Dipikir — Remotion Projects

Side project video explainer pendek: **“Yang biasa, belum tentu sederhana.”**

## Struktur

Setiap episode memiliki folder sendiri di `src/projects/NNN-slug/` agar mudah dicari, direvisi, dan dikembangkan. Sistem brand reusable berada di `src/brand/`.

## Episode

- `001-gratis-ongkir` — Gratis Ongkir — 40 detik, 1080x1920, 30fps.

## Preview

```bash
npm install
npm run studio
```

Buka composition `Coba-Dipikir / Episode-001-Gratis-Ongkir / E001-Gratis-Ongkir`.

## Audio

Episode #001 saat ini berisi visual + subtitle. Voice-over, musik, dan SFX belum dibundel agar preview tidak bergantung pada aset eksternal. Naskah narasi sudah tercermin pada subtitle dan storyboard scene.
